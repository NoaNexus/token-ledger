# Token Ledger v2.4.2 发行说明

Token Ledger v2.4.2 带来了更极致的 UI 原生统一性、更精准的公有云模型商用估值体系，以及印刷级的抗锯齿视觉体验：

---

### 🎨 核心界面与原生窗口统一

1. **Windows DWM 标题栏沉浸色动态双向联动**
   - 彻底告别写死黑框：原生 Windows 窗口框架（标题栏底色、文字颜色与边框）毫秒级动态跟随页面主题；
   - 浅色模式（Light）：标题栏自动切为纯净亮白（#F8FAFC），字体为钛黑（#0F172A），与数字后花园浅色背景 100% 融合；
   - 深色模式（Dark）：标题栏无缝切为深空灰黑（#090C10），字体为浅灰亮白（#EDEDED）；
   - PyQt5 原生监听 Qt 内部信号，零延迟响应，切换瞬间窗口底色与 DWM 一并平滑转换。

2. **卡片悬停字体变糊问题彻底修复**
   - 移除文字容器上的 3D 矩阵旋转（perspective rotateX/Y），消除 Chromium 渲染管线对 DirectWrite ClearType 亚像素抗锯齿的抑制；
   - 保留跟手光标动态投射的镜面高光反射（specular-glare），辅以印刷级抗锯齿样式注入；卡片浮雕光泽流转，而文字与数字始终 100% 锐利清晰。

---

### 💰 全模型定价与商用价值核算增强

1. **规避前缀匹配冲突（Prefix Collision）**
   - 定价目录严格按键名长度降序优先匹配，杜绝 gpt-4o-mini 误被 gpt-4o 抢先匹配、o1-mini 误被 o1 抢先匹配等情况。
   - 覆盖 OpenAI/Codex Frontier、Anthropic Claude、DeepSeek、Google Gemini、智谱 GLM、阿里通义千问等 30+ 种主流大模型。

2. **Claude Code 中转实付 vs 官方原生对标双轨核算**
   - 针对使用 CC Switch 转发至国产极速大模型（如智谱 GLM-Flash、DeepSeek-Flash，单价仅 0.10元/M 且享 95%+ 上下文缓存减免）的场景，不仅如实呈现其实付支出（个位数人民币），更贴心展示若运行于 Anthropic 官方 Claude 3.5 Sonnet 原生 API 的等额价值与降本率；
   - 鼠标悬停每个模型的绿色价格胶囊，均可浮动查看该模型的官方计费标准单价。

3. **走势图每日账单与 Tooltip 实时展示等额价值**
   - 悬停趋势图任意时间点，浮动 Tooltip 与下方的单日账单栏均实时展示该日期的精确等额价值。
