# Token Ledger v2.4.0 发行说明

### 🌟 核心更新亮点

#### 1. ⚡ 120 FPS 极速丝滑物理惯性滚动
- **物理惯性滑行算法**：采用时间微分（dt）指数衰减算法 `factor = 1 - exp(-11.5 * dt)`，单次齿格滑动约 140px 并平滑减速约 380ms，彻底消除 Windows 鼠标滚轮“一格一格跳动”顿挫感。
- **Canvas 渲染极速优化**：粒子晶格绘制执行单批次合并（Batch Draw），单帧开销由 7ms 降至 0.12ms，主线程帧率稳定锁定在 120 FPS（平均帧耗时 8.34ms）。
- **Edge 独立窗口高刷解锁**：在浏览器桌面启动参数中增加 `--disable-frame-rate-limit` 与 `--max-gum-fps=120`，全面释放高刷显示器性能。

#### 2. 📌 真·全屏贴顶毛玻璃置顶导航栏（Pinned Topbar）
- 重构为边缘到边缘贴顶毛玻璃横条（`top: 0`、`position: fixed`），彻底解决滑动时卡片在顶部缝隙穿出的视觉瑕疵。
- 智能体筛选胶囊（`全部 / Codex / Claude / Antigravity`）与观察时间范围常驻屏幕最顶端，无论滑到页面任何深处均可一键随时切换。
- 自适应紧凑布局设计，在 1280px、1366px 等笔记本屏幕下 100% 完整展示，无横向滚动条，无任何内容遮挡。

#### 3. 🌿 数字后花园旗舰美学与 3D 浮雕交互
- 深度对齐 `pjy.net.cn`（数字后花园）设计语言，引入 3D 透视浮雕卡片（`perspective(1000px) rotateX/Y`）与光标跟随的镜面高光反射（`specular-glare`）。
- 搭载流光粒子微节点力场画布与深空灰黑 / 纯净科技白双模式极简配色。

#### 4. 💰 模型公有云对标费用与商业价值折算引擎
- 内置主流大模型定价矩阵字典（GPT-4o/5, Claude 3.5 Sonnet, DeepSeek V3, Gemini 1.5/2.0 等）。
- 自动计算并呈现每个模型的输入、输出、缓存节约折算人民币（¥）与美元（$）商业价值。
- 关键 KPI 卡片直接呈现“等额商用价值”，一目了然看清为开发者节省的实际算力成本。

#### 5. 🔍 三大智能体深度全景视图与本地安全诊断
- **全智能体图景**：除 Antigravity 外，新增 Codex 官方额度窗口与 Prompt Cache 智能减负分析，新增 Claude Code & CC Switch 多路由全景看板。
- **本地优先安全诊断**：明晰展示各数据源发现文件数、有效事件数与存储路径，重申零云端上传、不持久化 Prompt、密钥免触与本地独享数据库承诺。
- **白屏彻底清零**：强化前端防护，为各大模块增加独立的错误捕获与防御性降级渲染。

### 🛠️ 质量与验证
- 全量 25 项自动化单元测试 100% 通过（耗时 1.30s）。
- 通过 Edge 无头自动化浏览器（CDP）实测验证：平均帧耗时 8.34ms（120 FPS），`top: 0` 滚动吸顶置顶验证通过。
