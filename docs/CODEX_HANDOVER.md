## 关键边界

- 修改前阅读 AGENTS.md；本项目修复不涉及 Codex 配置。
- 不终止未知端口占用进程，不发送凭据到按名称猜测的服务。
- 金额是 API 参考估算，未知模型不做模糊匹配。参考目录集中于 tokenledger/pricing.py。
- 不保存会话标题或正文；公开仓库不加入用户数据和真实账户截图。
- 升级清理旧衍生元数据，不删除用量事件。旧备份和 Git 历史未擦除；历史重写需另行明确授权。
- 身份未知的多源数据仍可能重叠；不要宣传精确实付或完整账单。
- Codex 源日志被截短时保留旧索引中的未证伪历史；只有父会话能够证实的继承副本才会在迁移中移除。该口径仍是本地日志下限，不等同于官方账户账单。
