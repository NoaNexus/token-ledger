## 已实施

桌面安全绑定和周期扫描；主题与屏幕适配；键盘和减少动画支持；真实额度降级；CC Switch 凭据目标约束及缓存身份；按来源覆盖对账；Antigravity 数据库变动检测与隐私清理；可追溯参考价格；仪表盘缓存失效；回归测试。详见发布说明和测试目录。

## 关键边界

- 修改前阅读 AGENTS.md；本项目修复不涉及 Codex 配置。
- 不终止未知端口占用进程，不发送凭据到按名称猜测的服务。
- 金额是 API 参考估算，未知模型不做模糊匹配。参考目录集中于 tokenledger/pricing.py。
- 不保存会话标题或正文；公开仓库不加入用户数据和真实账户截图。
- 升级清理旧衍生元数据，不删除用量事件。旧备份和 Git 历史未擦除；历史重写需另行明确授权。
- 身份未知的多源数据仍可能重叠；不要宣传精确实付或完整账单。

## 验证与发布

运行 python -m pytest -q；Windows 使用 TokenLedgerNative.spec 打包。Tag 触发 GitHub Actions 测试、打包与发布。发布必须同步版本、文档、源码和完整便携包；本地桌面快捷方式应指向可用完整应用目录。

后续可改进：按供应商账户稳定标识对账、更多已核验精确模型价格及历史有效期、Antigravity 协议版本兼容。没有证据时保留未提供。
