# Antigravity 集成边界

适配器读取本地 transcript 与关联会话数据库，优先使用结构化 Token 用量，缺失时明确标记文本估算。数据库及 WAL 的变化纳入重新解析判断，避免 transcript 未变化时遗漏数据库更新。

缺失模型字段时显示“模型未记录”，不默认指定 Gemini 型号。未变化的来源复用进程内统计缓存，但额度仍独立刷新；解析期间发生的来源变更会触发后续重读。

本机 Language Server 可提供服务端额度；不可用时显示未提供或真实旧缓存。不得填充固定百分比、重置日期或根据 Token 推算订阅额度。

解析过程可能读取正文，但账本不保存提示词、回复、思考正文或会话标题。工具和活动统计不能证明完整的计费用量。升级清理旧版持久化衍生元数据，不修改上游会话文件。

本地未公开协议可能随客户端变化；没有可靠数据时降级显示比猜测更准确。公开测试和文档仅使用合成样例。
