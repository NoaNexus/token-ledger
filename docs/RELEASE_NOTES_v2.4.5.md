# v2.4.5 — Codex 历史用量恢复与全周期统计加固

- **Codex 历史用量恢复**：完整恢复因长会话折叠压缩（Compaction）与过于激进的分叉去重而误删的约 28 亿历史 Token，全周期累计用量重回真实基准（约 58 亿 Codex Token / 66.7 亿全账本 Token）。
- **历史数据防裁切保护**：对经过确认的历史用量赋予永久保留标识（`codex-v2:h:`），防止后续常规扫描或强制全量重扫时因源日志压缩截短而丢失历史观测。
- **全周期 KPI 视角稳定**：首页左上首卡恢复为“全周期累计 Token”（全部历史），与今日新增、预估成本及官方额度保持全局核心指标体系统一；图表与明细数据继续跟随时间筛选（7天/30天/全部）动态刷新。
- **异步请求竞态防护**：增加前端异步请求序号验证（`dashboardRequestSerial`），防止快速连续切换过滤条件时因网络或渲染乱序导致数据串台。
- **回归与完整性测试**：71 项自动化测试与 Qt WebEngine 真实桌面端到端冒烟测试全数通过。
