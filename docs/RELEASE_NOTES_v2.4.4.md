# v2.4.4 — 桌面交互与排版修复

- 后台刷新不再短暂降低页面亮度；扫描进度更新不再反复重建卡片。
- 修复快速进出、反向移动鼠标时卡片背景异常拉伸：固定透视距离，逐帧更新受限角度，不再对透视矩阵做 CSS 过渡。
- KPI 与智能体卡片保留最高 ±4° 的背景俯仰，文字保持平面渲染；去除重复背景和双边框。
- 大图表与流程面板保持平整，镜面改为柔和的局部高光。
- “全部”等智能体筛选项改成胶囊形；恢复鼠标与键盘焦点区分，修复品牌文字间距。
- 修复旧桌面内核不支持 Flex gap 导致的拥挤排版：增加概览、智能体详情和诊断页间距，费用说明与金额分行。
- 窄窗口减少模型和数据源卡片列数，明细表在卡片内横向滚动。

## 验证

55 项自动化测试通过；本地 Qt WebEngine 实际页面验证覆盖深浅主题、480/900/1440 像素布局、胶囊圆角、文字位置稳定及 1200 次快速指针采样。

## 升级

下载并完整解压 TokenLedger-Windows.zip，运行 TokenLedger 文件夹内的 TokenLedger.exe；必须保留 _internal 目录。关闭旧版后再运行新版。应用数据位于独立用户数据目录，无需删除或重新导入。

本版不新增数据库迁移，不修改 Codex 配置。参考价格并非实际账单；旧 Git 历史、旧发布及本地备份不会因本次发布被清除。
