# v2.4.6 — 扫描性能优化、动态范围统计与原生窗口体验加固

- **扫描性能大幅优化**：在 usage_events(file_id) 上建立专用检索索引 idx_usage_file_id，消除清理遗留文件状态时的数千万次全表关联扫描，彻底解决扫描在 66% 处卡顿 30~40 秒的性能瓶颈，整体扫描时间缩短至毫秒级。
- **扫描调度策略改进（启动单次扫描 + 纯手动触发）**：将桌面后台调度策略由高频自动轮询调整为“应用启动 2 秒后自动执行单次增量扫描，后续转为纯手动触发”，移除后台反复自动重复扫描，显著降低本地系统资源与磁盘 I/O 占用。
- **动态时间范围 Token 统计**：概览首页顶部首卡完整联动时间范围切换（今天 / 7天 / 30天 / 全部），动态呈现所选观察窗口内的 Token 总量与会话统计，同时保留全周期历史底栏参考；针对单日（今天）走势图增强 SVG 脉冲基准线与高亮锚点渲染。
- **智能体切换与多维筛选联动**：强化智能体（Codex、Claude Code、Antigravity）与时间范围胶囊之间的状态统一、过渡动效及观察窗口文字同步，切换时即时响应无停滞。
- **原生桌面窗口与黑夜/白天沉浸标题栏恢复**：完整修复 PyQt5 运行时依赖，杜绝降级回退至 Edge 浏览器外壳；原生桌面窗口深度集成 Windows DWM API，窗口标题栏、边框与文本在暗黑（#090C10）与亮白（#F8FAFC）模式下实时动态精准变色。
- **Windows 二进制打包依赖加固**：完善 PyInstaller spec 配置，自动检测并收集 Anaconda/Python 环境下运行所需的 Qt5 核心库与 C 运行时依赖（sqlite3.dll 等），确保便携版在干净 Windows 环境下即开即用。
- **测试与质量保证**：76 项单元及集成测试、Qt 桌面无头端到端验证全数通过。

## 升级说明

下载并完整解压 TokenLedger-Windows.zip，运行 TokenLedger 文件夹内的 TokenLedger.exe；必须保留 _internal 目录。关闭旧版后再运行新版。应用数据位于独立用户数据目录，无需手动迁移。
