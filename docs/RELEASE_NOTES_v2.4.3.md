# v2.4.3 — 数据可信度与桌面安全修复

- 移除端口占用时终止其他 Python 进程的行为；使用独立绑定的本地端口。
- 修复桌面周期扫描、可用屏幕区域适配、主题切换和依赖声明。
- 恢复键盘焦点可见性及品牌按钮键盘操作；尊重减少动画偏好，避免较新数组 API 的兼容性问题。
- 移除写死的余额、额度和满额健康条；失败时仅保留真实旧值并标记过期，或显示未提供。
- DeepSeek 凭据使用依据已验证的官方地址，不依据 provider 名称；缓存身份不再仅使用密钥前缀。
- 对账限定在匹配平台、模型及路由覆盖内，避免独立用量被较大日汇总吞掉。
- Antigravity 关联数据库或 WAL 变化时重新解析；停止保存会话标题和提示词摘要。
- Antigravity 缺失模型字段不再默认指定型号；未变化来源复用统计缓存，减少重复读取。
- 升级时清理旧版 Claude / Antigravity 元数据和额度缓存，保留 Token 使用事件。
- 金额改为带来源与核验日期的 API 参考估算；未知模型显示未提供，混合汇总标记部分估算；删除静态省钱对标。
- 修复额度过期语义与仪表盘缓存失效；增加回归测试。
- 更新隐私、网络访问、计费边界及交接文档，移除公开文档中的个人样例。

## 升级

完整解压便携包后运行 TokenLedger.exe；保留 _internal 目录。应用数据位于独立用户数据目录，不需要删除或重新导入。升级清理的是可重建衍生缓存，不是 Token 使用事件。
