# 多源 Token 对账

CC Switch 日汇总与代理日志按本地日期、provider 和模型识别覆盖；同一覆盖选择总量较大的完整记录集合，不按整日排除所有代理数据。

Claude 会话和账户汇总在 Agent、本地日期、平台、模型及路由匹配时，保留总 Token 较大的一方。独立平台、模型和直连路由不能被另一来源吞掉。身份未知的记录不强行去重，因此可能重复，不能称为精确账单。

账户汇总无法还原会话数，session_count_complete 会说明不完整。临时读取失败应保留上次有效事件并报告部分扫描，不将错误当成空记录。

统计指标与计费不同：缓存读取仍可能有价格，净用量不等于实际计费量。回归测试使用合成数据，禁止加入真实账户统计或对话内容。
