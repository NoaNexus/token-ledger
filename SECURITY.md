# Security and privacy

Token Ledger is local-first. It indexes token counters and source fingerprints, not prompt or response bodies.

Please do not include the following when filing an issue:

- local SQLite databases or JSONL session logs;
- API keys, access tokens, cookies, account identifiers or screenshots containing them;
- complete home-directory paths if they identify a person or organization.

Report security issues privately to the repository owner instead of opening a public issue.
